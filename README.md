# Görev Listesi Uygulaması

React ve Bootstrap 5 kullanılarak geliştirilmiş bir TODO uygulaması.

## Özellikler
- Görev ekleme
- Görev listeleme
- Görev güncelleme
- Görev silme
- Öncelik seviyeleri (Düşük, Orta, Yüksek)
- Filtreleme (Hepsi, Aktif, Tamamlandı)

## Teknolojiler
- ReactJS
- Bootstrap 5
- Vite
